# Archived authorization Python tests

These 19 Python test modules were moved from `../../tools/` on 2026-10-22. Their
contents are retained as migration history and review references; they are not a
current test gate and must not be counted as Rust parity or a current `PASS`.
The archive directory is outside the Python tools discovery root, and no current
runner discovers or dispatches these modules.

The CURRENT V6 [per-method crosswalk](../../python-test-method-crosswalk.md)
retains 25 historical modules and 622 methods across this archive and the other
listed historical sources. Its current inventory is 599 `EQUIVALENT`, 9 `PARTIAL`,
0 `BLOCKED`, and 14 `RETIRED`. Equivalence applies only to the named offline or
supplied-input assertions; retired positive capabilities and partial mappings
are not equivalent coverage. These counts are inventory states, not executed
test results. Real dependency and deployment evidence remains separate.

The table below locates Rust replacements and their boundaries; the per-method
crosswalk determines individual coverage status. Named `BLOCKED` runtime suites
still require their stated prerequisites and observed postconditions. The
archived test files themselves are immutable migration references: several
docstrings, imports and readiness assertions refer to the former `tools/`
layout and are intentionally not executable.

For every archived `test_*.py`, a Rust campaign suite must list that archive path
in `sources`; `campaign::tests::manifest_entries_are_scoped_and_blocked_entries_are_not_dispatched`
checks the complete 19-file inventory and mapping table so additions cannot silently
escape either record.
