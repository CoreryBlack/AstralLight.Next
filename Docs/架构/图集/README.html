单接口调用链

文件说明
trace-explorer.html搜索 279 条接口，点选查看 Gateway → 中间件 → PolicyEngine/仓储 → MySQL/MQ 的分步链路与源码位置。

链路是契约级模型：来自路由注册、中间件和模块边界，不是运行时 trace；handler 内部调用需按给出的源码位置继续追。
